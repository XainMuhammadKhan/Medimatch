    How the NLP pipeline works

    Every search goes through these steps in the Python backend

    01

    Normalise & correct

    Input is lowercased and cleaned. Misspellings like “panadoll” are fixed with fuzzy string matching (RapidFuzz WRatio, Levenshtein-based).

    02

    Parse composition

    Text like “Paracetamol (500mg) + Caffeine (65mg)” is split into active salts and strengths. Regional spellings are mapped to one name (amoxicillin → amoxycillin).

    03

    Exact substitutes

    Medicines with the identical set of salts count as direct replacements. Ones with the same strength are listed first, then they're sorted by user reviews.

    04

    TF-IDF similarity

    Salts and the “uses” text are turned into TF-IDF vectors. Cosine similarity (65% salts, 35% uses) finds close alternatives, and symptom searches use word 1–2-grams with lay-term query expansion.

    ⚠️ This is an academic NLP project, not medical advice. Check with a doctor or pharmacist before switching medicines, especially for different strengths or combinations.
